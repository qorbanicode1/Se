# سیستم مدیریت کتابخانه دانشگاه

پروژه‌ی درس مهندسی نرم‌افزار — پیاده‌سازی سیستم مدیریت کتابخانه دانشگاه با زبان **Python** و دیتابیس **SQLite** (بدون نیاز به نصب هیچ پکیج خارجی).

## نحوه‌ی اجرا

```bash
python main.py
```

حساب پیش‌فرض مدیر کتابخانه (در اولین اجرا ساخته می‌شود):

- نام کاربری: `admin`
- رمز عبور: `admin123`

## ساختار پروژه

| فایل | توضیح |
|------|-------|
| `main.py` | رابط کاربری خط فرمان (منوهای دانشجو / کارمند / مدیر / مهمان) |
| `services.py` | منطق کسب‌وکار و تمام قواعد سیستم |
| `database.py` | ساخت دیتابیس، جداول و حساب پیش‌فرض مدیر |
| `auth.py` | هش کردن رمز عبور (PBKDF2-HMAC-SHA256) |

دیتابیس در فایل `library.db` در همان پوشه ساخته می‌شود.

## نقش‌ها و قابلیت‌ها

### دانشجو
- ثبت‌نام در سیستم با انتخاب نام کاربری و رمز عبور (به‌صورت پیش‌فرض فعال است)
- ورود به سیستم
- جستجوی کتاب با ترکیب عنوان / نویسنده / سال نشر و مشاهده وضعیت امانت (موجود یا در امانت)
- ثبت درخواست امانت با بازه زمانی (زمان شروع و پایان)

### کاربر مهمان (بدون ورود)
- مشاهده تعداد دانشجویان ثبت‌نام‌شده
- جستجوی کتاب فقط بر اساس نام (بدون نمایش وضعیت امانت)
- آمار ساده: تعداد دانشجویان، کتاب‌ها، امانت‌ها و آخرین کتاب‌های در امانت

### کارمند کتابخانه (ثبت‌نام کارمند توسط مدیر انجام می‌شود)
- ورود و تغییر رمز عبور
- ثبت اطلاعات کتاب
- جستجو و ویرایش اطلاعات کتاب
- بررسی و تایید/رد درخواست‌های امانتی که تاریخ شروعشان «امروز» یا «دیروز» است
- تحویل کتاب تاییدشده به دانشجو و دریافت کتاب برگشتی با ثبت زمان
- گزارش تاریخچه امانات یک دانشجو + آمار (کل امانات، تحویل‌نشده، با تاخیر)
- فعال/غیرفعال کردن دانشجو (دانشجوی غیرفعال نمی‌تواند امانت بگیرد)

### مدیر کتابخانه
- تعریف کارمند (نام کاربری و رمز عبور)
- گزارش عملکرد کارمند: تعداد کتاب‌های ثبت‌شده، امانت‌های داده‌شده و تحویل‌گرفته‌شده
- آمار امانات: تعداد درخواست‌ها، کل امانت‌های داده‌شده، میانگین روزهای امانت
- آمار همه دانشجویان (مانند گزارش ۳-۶) + ۱۰ دانشجو با بیشترین تاخیر

## مفاهیم وضعیت امانت (Loan)

```
pending  →  approved  →  borrowed  →  returned
    └→ rejected
```

- `pending`: درخواست ثبت شده و منتظر بررسی کارمند است
- `approved`: کارمند تایید کرده؛ دانشجو باید برای تحویل گرفتن مراجعه کند
- `borrowed`: کتاب تحویل دانشجو شده است
- `returned`: کتاب برگردانده شده؛ اگر تاریخ برگشت بعد از پایان بازه امانت باشد، «با تاخیر» است
